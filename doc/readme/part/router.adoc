= The Router
:revnumber: 1.5.0
:revdate: 2026-10-13

`Inane\Routing\Router` holds the routes, matches them against the request and builds urls from them.

.Router constructor
[source,php]
----
use Inane\Routing\Router;

$router = new Router(
    routes: [MainController::class],   // controllers and/or route configurations
    baseURI: '/app',                   // part of the uri to exclude when matching
    splitQuerystring: false,           // separate the querystring from the path
);
----

[cols="1,1,2,3",options="header"]
|===
|Parameter |Type |Default |Description

|`routes`
|`array\|OptionsInterface`
|`[]`
|Controller class names carrying `Route` attributes and/or route configuration arrays.

|`baseURI`
|`string`
|`''`
|Part of the uri to strip before matching, useful when the project is served from a subfolder. Also prefixed onto generated urls.

|`splitQuerystring`
|`bool`
|`false`
|When `true` the querystring is removed from the path being matched and its values are parsed into the `query-string` parameter.
|===

== Adding routes

Routes come from two sources, both handled by `addRoutes()`: controller classes using the `Route` attribute, and route configuration arrays keyed by the route name.

.addRoutes
[source,php]
----
$router->addRoutes([
    MainController::class,
    BlogController::class,
    'backups' => [
        'route'  => [
            'path'    => '/archive/{section}/year/{id<\d+>}',
            'methods' => ['GET'],
        ],
        'class'  => HistoryController::class,
        'method' => 'list',
    ],
]);
----

CAUTION: An entry that is neither an existing class nor a configuration array raises an `InvalidRouteException`.

TIP: `setBaseURI()` sets the base uri after construction; both it and `addRoutes()` return the router so calls may be chained.

== Matching a request

`match()` walks the routes in the order they were added and returns a `RouteMatch` for the first route whose path *and* http method satisfy the request, otherwise `null`. Pass a `Inane\Http\Request` to match something other than the current request.

.match
[source,php]
----
if ($match = $router->match()) {
    $controller = new $match->class();
    $controller->{$match->method}($match->params);
}
----

== Building urls

`url()` delegates path generation and parameter validation to the named route's `getURL()` method, then prefixes the router's base URI. Calling `Route::getURL()` directly does not include that prefix. Additional parameters are ignored rather than appended as a querystring; parameter values are not URL-encoded.

.url
[source,php]
----
$router->url('blog-index');                 // /blog
$router->url('blog-post', ['id' => 7]);     // /blog/7
----

Each value is checked against the placeholder's regular expression, so:

* an unknown route name throws an `OutOfRangeException`;
* a missing parameter, or one that fails its regular expression, throws an `InvalidArgumentException`.

== Named-route lookup

`getRoute(string $routeName): ?Route` returns the registered `Inane\Routing\Route` object, or `null` for an unknown name. Unlike `url()` and `routeProperty()`, an unknown name does not raise an `OutOfRangeException`.

The returned object is shared with the router and any corresponding `RouteMatch`. A successful match sets its `active` state to `true`; unsuccessful matches do not activate routes. Previously active routes are not automatically reset on subsequent calls.

== Route properties

`routeProperty()` reaches the `extra` values of a named route, the parameters supplied fill out the value's `{name}` tokens.

.routeProperty
[source,php]
----
$router->routeProperty('blog-post', 'title', ['id' => 7]); // Article 7
----

== Querystrings

With `splitQuerystring` enabled the querystring no longer takes part in the path matching and is instead parsed into the parameters under the `query-string` key.

.splitQuerystring
[source,php]
----
// GET /search?q=robot&page=2
$router = new Router([SearchController::class], splitQuerystring: true);

$match = $router->match();
$match->params['query-string']; // ['q' => 'robot', 'page' => '2']
----

== Exceptions

All exceptions live in the `Inane\Routing\Exception` namespace.

[cols="1,3",options="header"]
|===
|Exception |Thrown when

|`InvalidRouteException`
|A route entry is neither a known class nor a valid configuration.

|`OutOfRangeException`
|The requested route name is not registered.

|`InvalidArgumentException`
|A route parameter is missing or does not match its regular expression.
|===
